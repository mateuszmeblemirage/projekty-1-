Skąd wziąć klucz? (instrukcja dla właściciela strony)
  1. Zaloguj się na github.com na konto, do którego należy strona.
  2. Wejdź w: zdjęcie profilowe → Settings → na dole Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Token name: np. „Panel AGMAT”. Expiration: wybierz najdłuższy możliwy termin.
  4. Repository access: Only select repositories → wybierz projekty-1-.
  5. Permissions → Repository permissions → Contents: ustaw Read and write.
  6. Kliknij Generate token, skopiuj klucz i wklej go tutaj.

Klucz traktuj jak hasło – nie wysyłaj go nikomu poza agentem.
